Unlock vault

Use 6–63 UTF-8 bytes (6–63 characters for digits and English letters). Keep this credential safe: there is no PIN recovery.

SD card USB drive

The host gets a normal FAT32 drive backed by encrypted data on the microSD card, using nearly all currently free card space. Safely eject it in Windows before locking or changing settings. Auto-lock waits while the USB drive is connected.

Phone/client files below are a separate file area. Existing files can be downloaded or deleted after the USB drive is ejected. Add new files through the USB drive. No files are stored in the ESP32 internal flash.

Phone/client files

Device settings

Settings are saved on the device. Restart to apply network, USB and display changes. Auto-lock uses the saved timeout immediately; status polling does not keep the vault unlocked.

Change vault credential

A PIN or passphrase protects the encryption key. USB/FIDO security keys are not supported by this firmware.

Wi-Fi stays available while locked. Files on the SD card are encrypted; this local control page uses HTTP over your WPA2 network. Anyone with USB access can use the vault while it is unlocked. Change the default Wi-Fi password in settings.
